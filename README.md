# Air Quality Analysis & CO2 Prediction

A Python-based ML project for predictiction CO2 concentration based on atmospheric chemical composition data

## Key Features
* **Data Preprocessing:** Cleaning raw features in datasets, handling missing values using interpolation where it's suitable, and removing NULL values
* **Feature Engineering:** Multicollinearity analysis to ensure feature independence and improve model stability
* **Predictive Modeling:** Training a regression model to estimate CO2 levels with high accuracy

## Tech Stack
* **Python** (Pandas, NumPy)
* **Scikit-learn** (Machine Learning)
* **Matplotlib** (Data Visualization)
